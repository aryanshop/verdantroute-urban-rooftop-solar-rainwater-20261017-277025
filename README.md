# VerdantRoute: Urban Rooftop Solar & Rainwater Harvesting Estimator

VerdantRoute is an interactive sustainability calculator and spatial planning workbench designed for urban homeowners, architects, and green building enthusiasts. It allows users to simulate rooftop photovoltaic (solar) energy generation and rainwater harvesting capacity based on specific roof dimensions, climate zones, and local utility rates.

## Key Features

- **Interactive Roof Grid**: Configure roof width and length, then click/drag to place solar panels on an interactive visual grid.
- **Solar PV Estimator**: Instantly calculates annual kilowatt-hour (kWh) production, estimated financial savings, and CO₂ carbon offset.
- **Rainwater Harvesting Calculator**: Computes annual catchment yields, recommends optimal cistern storage tank sizes, and estimates municipal water bill reductions.
- **Interactive Visualizers**: Includes dynamic monthly generation profile charts and a visual water tank level indicator.
- **Audit & Report Generator**: One-click professional sustainability audit report modal ready for printing or export.

## Local Run Instructions

1. Download or clone all project files (`index.html`, `style.css`, `script.js`, `README.md`) into a single folder.
2. Open `index.html` in any modern web browser (Chrome, Firefox, Safari, Edge).
3. No installation, build steps, or external network requests are required.

## Technology Stack

- Pure **HTML5**, **CSS3**, and vanilla **JavaScript (ES6+)**.
- Fully offline-capable static application with responsive grid layout and CSS variables.
